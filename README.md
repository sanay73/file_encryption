 🔐 File Encryption Tool

 ✨ Features

- 🔒 Encrypt files securely
- 🔓 Decrypt encrypted files
- 📁 Supports files from different folders
- 🖥️ Simple and attractive terminal interface
- ⚡ Easy to use
- 🐍 Built with Python

🚀 Installation

Clone the repository:
git clone https://github.com/YOUR_USERNAME/file-encryption-tool.git

Enter the project directory:
# cd file-encryption-tool

Create a virtual environment:
python3 -m venv venv

Activate it:
source venv/bin/activate

Install the required package:
pip install cryptography

Run the tool:
python3 encryptor.py
Select the file you and follow the instructions shown by the tool.

⚠️ Important
Always keep your encryption key/password safe.
Do not upload private keys or passwords to GitHub.
Test the tool with sample files before using important data.
Keep backups of important files.
